# LifeBalance

## About the Project
LifeBalance is a personal management web application designed to help users organize their daily tasks and manage their finances in one place.

## Features
- **Dashboard:** View daily tasks, task progress, and financial summaries.
- **Tasks:** Add tasks and mark them as completed using checkboxes.
- **Budget:** Record income, expenses, and savings, and view recent transactions.
- **Currency Settings:** Choose between FCFA, EUR, and USD.
- **Appearance Settings:** Switch between light mode and dark mode.
- **Data Storage:** Uses Local Storage to save tasks, financial information, and preferences.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage
